## About me

I'm a full stack engineer at Cognizant in Hyderabad. For the last four years I've been building enterprise apps for Bayer, with React and TypeScript on the front end, Node.js and Express on the back end, PostgreSQL and MongoDB for data, and AWS (ECS Fargate, Lambda, S3) to run it all.

Right now I'm on **Bayer PIM**, a product information platform used by 500+ people. A growing share of that work is LLM features: retrieval pipelines, agents, and the plumbing that keeps a model's answers tied to real data.

Ask me about React, Node.js, AWS, or getting a RAG pipeline to retrieve the right chunks.

## What I'm building with LLMs

**RAG for product search at Bayer.** Product data is split into chunks and run through an embedding model, and the vectors are stored in a vector database. When someone searches, the closest chunks are retrieved and given to the LLM as context, so the answer comes from Bayer's own product data rather than the model's memory. LangChain ties the steps together, and the prompts keep answers grounded in what was retrieved.

**Agents and MCP.** Agent workflows on the OpenAI API, with internal tools exposed through the Model Context Protocol, automating processes the team used to run by hand. That has cut the manual effort in those processes roughly in half.

**Frontier and embedding models.** I build on Claude and GPT through their APIs and use embedding models for retrieval. Claude Code, Cursor and GitHub Copilot are part of my day-to-day workflow.

## Projects

### Ask My Portfolio

[![Try it](https://img.shields.io/badge/Try%20it-on%20my%20portfolio-7C3AED?style=flat&logo=vercel&logoColor=white)](https://shashankraskas.vercel.app/)

A RAG assistant built into my portfolio site. The site's content is chunked into an in-memory vector index, each question is matched against it by cosine similarity, and Claude streams back an answer along with the sources it used.

**Stack:** Next.js · TypeScript · Claude API · vector search · streaming

### Food Ordering Platform

[![Live demo](https://img.shields.io/badge/Live%20demo-Render-000000?style=flat&logo=render&logoColor=white)](https://foodorderapp-99re.onrender.com)
[![Code](https://img.shields.io/badge/Code-foodOrderApp-181717?style=flat&logo=github&logoColor=white)](https://github.com/Shashank-Raskas/foodOrderApp)

A full stack ordering app: React with Context API on the front end, a Node.js/Express REST API, and Firebase Firestore for real-time data. It covers the cart and order management, sign-in with OTP over email or SMS plus JWT sessions, and an admin dashboard. Hosted on Render.

**Stack:** React · Node.js · Express · Firestore · Nodemailer · Render
